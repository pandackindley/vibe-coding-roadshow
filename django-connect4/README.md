# Django Connect4 Hello World

## How to Run Locally

1. Ensure you have Python 3 and pip installed.
2. (Recommended) Create and activate a virtual environment:

   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   ```

3. Install dependencies:

   ```powershell
   pip install Django
   ```

4. Run the development server:

   ```powershell
   python manage.py runserver
   ```

5. Visit [http://127.0.0.1:8000/](http://127.0.0.1:8000/) in your browser. You should see a hello world page with the Django version.

---
This is a minimal Django project for local development and testing.
